# 成员 1 报告内容：Data Description 与 Data Quality

## Data Description

训练集包含 24,896 条成对猫咪图片选择记录，覆盖 237 只猫、1,296 张图片。每条记录包含 A/B 两侧图片和猫咪标识、选择结果、比较类型及六个人群属性。21,893 条（87.94%）比较来自不同猫，3,003 条（12.06%）比较同一只猫的不同照片。总体选择 A 的记录为 12,921 条（51.90%），选择 B 为 11,975 条（48.10%）。这些是回答记录数，而非独立参与者人数。

训练集包含 8,049 个无序图片对，其中 7,627 对出现多次，每对有 1–4 条回答。不同猫比较包含 6,917 个图片对，同猫比较包含 1,132 个图片对。不同猫比较中，每只猫出现 148–220 次。图片对层面的回答数量较少，观察到的一致选择不能直接解释为强总体共识。

## Data Quality and Preparation

训练行 ID 唯一，所有选择和比较类型有效，比较类型与猫咪 ID 一致。未发现图片自身比较、图片路径或文件名与猫咪 ID 不一致或引用图片文件缺失。训练和测试引用的 1,558 张图片均可在本地找到，并全部通过文件验证与完整解码；没有字节内容完全相同的图片文件。这不等于已人工检查图片内容或排除视觉相似图片。

六个人群字段各缺失 508 条（2.04%），且发生在同一批记录中；未出现仅部分人群字段缺失的记录。保留这些记录供总体偏好分析，并添加缺失标记；人群分析需要另行说明处理。MBTI 的 unknown 作为有效类别保留。去掉行 ID 后，有 46 个内容重复组，每组两条，共 92 条被标记记录，相当于 46 条额外重复。由于没有参与者 ID，无法判断它们是否属于重复录入，因此主数据保留并标记。

使用排序后的图片路径构造无序图片对 ID，并把选择转换为是否选择排序后的第一张图片，避免 A/B 交换导致统计方向错误。训练集中 7,114 个图片对同时出现两种朝向，方向转换经过逐行检查。保留全部训练记录，未填补人群属性、删除重复记录或改写原始有效值；本批数据无需要修正的首尾空格。另保留随机种子 2026 的图片对分组验证划分作为可选附加文件，它不影响主清洗数据。

## 图注与描述性结论

**图 1：比较类型与选择分布。** 左图基于全部 24,896 条训练记录，标注两类比较的记录数和占比；右图分别以 21,893 条不同猫比较及 3,003 条同猫比较为分母。选择 A 的比例分别为 51.97% 和 51.42%。两类均略高于一半，但不能直接归因于位置效应。

**图 2：猫咪与图片对的数据覆盖。** 左图统计 237 只猫在不同猫比较中的出场次数（148–220 次）；右图统计各类无序图片对的回答数。共 8,049 对，其中 422 对只有一次回答，7,627 对有 2–4 次回答。猫咪出场次数既不是独立参与者人数，也不是独立对手数量。

**图 3：养宠经历与人群信息缺失。** 左图所有比例以全部训练记录为分母：never 9,315 条、past 6,423 条、current 8,650 条、缺失 508 条。右图六个字段各缺失 508 条，且均来自同一批记录，不应把六个缺失计数相加当作缺失人数。此图描述回答构成，不检验群体偏好差异。

## Limitations

* 无标注者 ID，无法确定独立参与者人数、直接测量个人重复选择一致性，或完整控制个人内相关性。
* 每个图片对仅 1–4 条回答，单对偏好比例不稳定；猫咪排名仍需后续不确定性分析。
* A 的总体选择比例略高于一半；缺少随机分配机制信息，不能仅据此认定位置偏差。
* 按图片对分组的验证仍可共享猫咪和图片，只支持相应泛化目标。
* 测试集有 47 只新猫、262 张新图片；只依赖训练猫咪参数的模型需要明确回退策略。
* 外观特征没有结构化标注；哪些猫或图片更受偏好，与哪些外观特征导致偏好，是不同层次的问题。
