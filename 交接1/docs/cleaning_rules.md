# 统一清洗与交接口径

1. 原始 CSV 和图片不修改；全部处理使用相对路径。
2. 明确按文本读取字段；仅把空单元格识别为缺失，避免把 NA 等未知字面值自动吞成缺失。去除字符串首尾空格，空白字符串转为缺失；不改变有效类别含义。本次训练和测试均没有实际修正的单元格。
3. 检查 CSV 列名、重复列名和行宽，再检查行 ID、必要字段、选择类别、人群类别、比较类型逻辑、图片路径及文件名中的猫咪 ID、自身比较和图片存在性。猫咪 ID 采用 cat_加六位数字、图片采用猫咪目录/猫咪ID_四位编号.jpg 的当前数据格式；未来若数据格式更新，应先确认再调整校验规则。所有引用图片还需通过 Pillow 验证和完整解码。关键错误使程序停止，先解决再交付，不静默删除。
4. 人群字段缺失保留，添加缺失标记。总体分析可使用这些记录；具体人群比较再明确排除缺失或单独展示。unknown 不替换为缺失。
5. 重复图片对保留；同一图片对的多条回答是群体分歧信息。
6. 去除行 ID 后的完全相同记录只标记，不删除：没有参与者 ID，可能是不同人的相同回答。训练集为 46 个重复组，每组 2 条，额外重复为 46 条，标记 True 的行数为 92。测试集已知字段重复为 29 组、58 行，额外重复为 29 条。A/B 顺序互换的记录通过 image_pair_id 合并识别图片对，但不算“原字段内容完全相同”。
7. 统一无序图片对并同步转换选择方向。保留 A/B 原字段，可分析位置倾向。
8. 不做标签填补、人群属性推断、数值标准化、模型拟合或图片特征提取。
9. 测试集 choice/prob_a 缺失是正常情况。test_example.csv 不参与清洗、训练和效果评估，示例值不视为真实标签。
10. 不默认删除任何训练行。所有质量检查计数保存在 outputs/tables/quality_check_summary.csv。

## 本次处理的实际变动

训练集仍为 24,896 行，测试集仍为 6,224 行；原始字段值、行 ID 和行顺序保留。没有删行、填补人群信息、纠正标签、合并回答或去除重复。主要产物是经过核验的原始数据加辅助字段，而非大规模“修正”后的样本。输入文件指纹保存在 outputs/run_metadata.json。

缺失标记只描述是否缺失，不证明缺失完全随机；保留重复记录也不证明它们来自不同人。缺少参与者身份造成的限制无法靠清洗消除。

## 验证划分

对排序后的唯一 image_pair_id，用 NumPy default_rng(2026) 打乱，前 ceil(20% × 图片对数) 个图片对作为验证集。其余为训练集；一对的全部回答在同一集合。
当前验证集 4,915 条记录；20% 指图片对比例，并非强制记录比例。划分不按选择标签筛选。
该划分允许猫咪和图片共享，衡量未见图片对的表现，不能证明新猫、新图片或新参与者泛化。成员 2/5 需报告各划分中猫咪覆盖，并明确模型对未见猫的处理。
这是一份建议的共同划分；全数据描述统计与用于验证的训练数据要区分。拟合、调参与需要从数据学习的预处理仅使用相应训练部分。

## 分工交接

- 成员 2：train_clean.csv 中 between_cats；结合 cat_coverage.csv 和 validation_split.csv。
- 成员 3：within_cat 逐行数据和 image_pair_summary.csv；少量回答的表面一致性不等于真实一致性。
- 成员 4：逐行数据中的 pet_history 等变量及缺失标记；报告回答记录数，避免声称独立人数。
- 成员 5：共同验证划分、质量报告、图表和数据局限；考虑内容重复处理敏感性分析。

数据只供教育与研究使用。未增加外部图片、标签、预训练模型或其他研究数据。

## 图表统一规范

图表仅使用全训练集，单位写为 response records / image pairs / cats，不把记录数标为人数。类别占比以全训练集为分母并包含缺失；类型内部的 A/B 比例以各类型记录数为分母。蓝色 #377EB8、橙色 #F0A44B 为配色，各子图通过类别标签说明含义；不跨图把颜色解释为同一个变量。统一字体、轴线和两位小数的比例标注；导出 300 dpi PNG 及矢量 PDF。图中不报告显著性或因果结论。
