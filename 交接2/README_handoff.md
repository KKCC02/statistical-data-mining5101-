## 5. 方法说明

### 经验胜率

`win_rate = wins / (wins + losses)`。

每条比较产生一次胜和一次负，因此全体猫咪的获胜次数之和、落败次数之和均应为 21,893；比较次数之和为 43,786。Notebook 中用断言检查了这些关系。

经验胜率直观，但没有调整对手构成。两只猫即使胜率相近，也可能面对不同的比较对手。

### Bradley–Terry 模型

每只猫有一个分数 `u_i`，模型假设：

```text
P(选择猫 i 而不是猫 j) = 1 / (1 + exp(-(u_i - u_j)))
```

分数越高，模型预测它越容易被选中。分数本身不是概率，分数之差才决定两猫之间的预测概率。

代码把每条记录写成“获胜猫与落败猫”，最小化平均负对数似然：

```text
mean(log(1 + exp(-(u_winner - u_loser))))
```

使用自然对数、解析梯度和 L-BFGS-B 优化器，不添加正则化项。初始自由分数全为 0；`maxiter=5000`、`gtol=1e-8`、`ftol=1e-12`。本流程没有随机抽样或随机初始化，不需要随机种子。

由于所有分数同时增加一个常数不会改变概率，拟合时将按猫咪 ID 排序后的第一只猫的分数固定为 0。拟合结束后再减去全部分数的平均值，使展示分数均值为 0；这不改变排名和预测。

完整数据的有向胜负网络只有一个强连通分量，满足普通 BT 模型在固定基准后存在唯一有限估计的条件。保存的运行输出显示优化成功，最大自由参数梯度绝对值约为 `9.02e-9`。

## 6. 排名表字段怎么看

| 字段 | 含义 |
| --- | --- |
| `cat_id` | 猫咪 ID，作为文本读取 |
| `comparisons` | 出现于不同猫比较记录的次数，不是不同对手数量或人数 |
| `wins` / `losses` | 获选次数 / 未获选次数 |
| `win_rate` | 经验胜率，0.75 表示 75% |
| `win_rate_rank` | 经验胜率排名，1 为最高；相同值按最小名次并列 |
| `bt_score` | 中心化后的 BT 分数，越高表示相对偏好越高 |
| `bt_rank` | BT 分数排名，1 为最高 |
| `rank_change` | `win_rate_rank - bt_rank`，正数表示 BT 排名上升，负数表示下降 |

例如，经验排名 149、BT 排名 89，则 `rank_change=60`，表示上升 60 名。负的 BT 分数不代表负概率，也不代表没有人喜欢这只猫。

## 7. 主要结果和图表解释

- 两种排序的 Spearman 相关系数为 **0.9730**，表示整体排序高度一致，不是“97.3% 的预测准确率”。
- 两种方法的前十名名单完全重合，但内部顺序有变化。
- `cat_000024` 在两种方法中均排名第一，201 次比较中获胜 150 次，经验胜率约 **74.63%**，BT 分数约 **1.4303**。
- `cat_003674` 在两种方法中均排名最后，167 次比较中获胜 40 次，经验胜率约 **23.95%**，BT 分数约 **-1.4809**。
- `cat_005010` 从经验排名 149 升至 BT 排名 89；`cat_001761` 从 126 降至 175。

排名比较图中，每个点是一只猫。虚线表示两种名次相同；虚线下方表示 BT 排名上升，上方表示下降。

条形图左侧为 BT 第 1–10 名，右侧从最后一名开始展示后十名；`n` 是比较记录数。两图采用相同横轴刻度。图中没有置信区间，不应把很小的分数差直接解读为显著差异。

整体一致但局部变化说明，考虑对手后某些猫咪的相对排序会改变。不过，仅凭排名变化不能断言某只猫面对的对手特别强或特别弱，需要另查对手构成。

## 8. 成员 5 如何接着使用

### 展示已有描述性结果

可以直接读取完整排名比较表，使用两张图及 Notebook 末尾的英文方法和结果说明。

对于表中已有的两只猫，预测 A 被选中的概率为 `expit(u_A - u_B)`。该表的分数是在全部 21,893 条比较上拟合的，只适合这份全数据描述性分析或后续适用场景的预测，不可拿来评估已参与拟合的验证记录。

### 比较基础模型与扩展模型的验证表现

1. 按 `train_row_id` 将成员 1 的 `validation_split.csv` 与逐行数据连接，检查没有缺失或重复连接。
2. 两个子集均只保留 `between_cats`；仅用 `split=train` 的记录拟合基础模型。
3. 重新建立训练子集的猫咪索引、胜负索引和胜负网络，检查强连通性及收敛情况。
4. 使用训练得到的分数对验证记录计算 `P(A)=expit(u_A-u_B)`，真实标签使用 `choice_a`。
5. 基础模型和扩展模型使用同一验证集、同一评估口径。

**不能直接使用当前全数据分数评估验证集，这会造成信息泄漏。** 当前 Notebook 的 `bt_objective` 依赖上方创建的 `winner_idx`、`loser_idx`、`n_cats` 和 `between`，它还不是独立的可复用拟合接口。不要只复制优化器单元格就用于新的子集；需要重新构建这些变量并重跑相关步骤，或先封装拟合函数。

如果训练子集网络不再强连通，或验证集中出现训练未覆盖的猫，需要另外制定并记录处理方案，不能用全数据分数补进去。Notebook 的连通性检查目前仅打印提示，不会自动阻止后续拟合，因此改用子集时尤其要检查输出。

成员 1 的划分按图片对分组，同一图片对不会跨训练和验证，但猫咪和图片可能跨集合。它不等于“新猫泛化”或“新参与者泛化”的评估。

## 9. 解读边界

- 基础模型每只猫只有一个分数，没有单独调整照片差异、人群属性或 A/B 展示位置。
- 排名反映这批被展示猫咪图片中的偏好，不应直接表述为猫咪固有吸引力或全体人类的共同偏好。
- 没有参与者 ID，不能确认所有回答相互独立，也无法按参与者做聚类不确定性估计。
- 两种排名一致不等于换一批数据后排名稳定；本部分未进行 bootstrap、置信区间或显著性检验。
- 目前没有计算验证准确率、验证 log loss 等预测指标，不应将 Spearman 相关系数当作预测性能。
